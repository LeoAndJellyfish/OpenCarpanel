# F1 25 UDP 适配器资料与边界

## 权威资料

- [EA SPORTS F1 25: 2026 Season Pack UDP Specification](https://forums.ea.com/blog/f1-games-game-info-hub-en/ea-sports%E2%84%A2-f1%C2%AE25-2026-season-pack-udp-specification/12187347)
- **核验日期：** 2026-08-14
- **实现基线：** EA 发布的原始 F1 25 v3 与 2026 Season Pack v10.0 两份附件。

游戏同时保留原始 F1 25 与 2026 Season Pack 两种 UDP mode。OpenSimDash 用稳定 adapter ID `f1-25` 接受 `packetFormat = 2025` 和 `2026`；切换 mode 不会改变 Dashboard 的游戏身份或用户布局。

## 精确 packet 矩阵

两种格式都使用 29 字节 packed、小端公共头。decoder 只根据已经验证的 `packetFormat` 选择固定布局，不用相近长度或字段值猜测协议：

| Packet | ID | 原始 2025 | 2026 Season Pack |
| --- | ---: | ---: | ---: |
| Session | `1` | 753 bytes | 926 bytes |
| Lap Data | `2` | 1285 bytes（22 × 57） | 1399 bytes（24 × 57） |
| Event | `3` | 45 bytes | 45 bytes |
| Car Telemetry | `6` | 1352 bytes（22 × 60） | 1448 bytes（24 × 59） |
| Car Status | `7` | 1239 bytes（22 × 55） | 1445 bytes（24 × 59） |
| Car Damage | `10` | 1041 bytes（22 × 46） | 1133 bytes（24 × 46） |
| Car Telemetry 2 | `16` | 不存在 | 269 bytes（24 × 10） |

2026 把车辆上限从 22 提高到 24，把 Car Telemetry entry 的发动机温度由 `uint16` 改为 `uint8`，并在 Car Status 增加 ERS harvesting limit。错误总长、车辆索引、packet version、布尔值、枚举、百分比或非有限浮点都会返回有类型的错误。

## 当前输出

- **驾驶：** 速度、档位、RPM/RPM 上限、转速灯、油门、刹车、DRS、维修区限速器、燃油与 ERS。
- **比赛：** 圈号/位置、圈速与分段、前车/领跑者差距、赛道距离、维修区计时、处罚/警告、车手与结果状态。
- **Session：** 赛制、赛道、剩余时间、总圈数、安全车、FIA 旗帜、天气、空气/赛道温度和维修区限速。
- **轮胎与损伤：** 四轮温度、胎压、磨损、损伤、刹车损伤、配方、圈龄；F1 25 还包含起泡程度；车身和动力单元损伤/故障。
- **事件：** 比赛开始/结束、最快圈、处罚、退赛、DRS、超车、安全车、红旗、碰撞等结构化事件，以及从圈号变化生成的 `lap.completed`。

所有数组严格按官方 `rear-left, rear-right, front-left, front-right` 顺序转换为统一模型的具名四角字段。

## 2026 Car Telemetry 2（packet 16）

每辆车的 10-byte entry 完整映射如下：

| Entry offset | Type | 字段 |
| ---: | --- | --- |
| `0` | `u8` | active aero mode：弯道 / 直道 |
| `1` | `u8` | active aero available |
| `2` | `u16` | active aero activation distance，m |
| `4` | `u8` | overtake available |
| `5` | `u8` | overtake active |
| `6` | `u16` | overtake activation distance，m |
| `8` | `u8` | 2026 regulations active |
| `9` | `u8` | driving wrong way |

该 packet 只在 format `2026` 接受；format `2025` 不会尝试解析。主动空气动力学状态进入统一 `aero` 字段组，前端无需读取 F1 私有偏移。

## 明确边界

- 不解析 Motion、Participants、Final Classification、Lobby、Tyre Sets、Time Trial 等未列出的 packet。
- 不从 `2024`、未知年份、未知 packet version 或错误长度推断兼容。
- F1 24、原始 F1 25 与 2026 Season Pack 共用安全 cursor，但使用彼此隔离的精确布局和交叉拒绝测试。
