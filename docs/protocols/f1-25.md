# F1 25 UDP 适配器资料与边界

## 权威资料

- [EA SPORTS F1 25 / 2026 Season Pack UDP Specification](https://forums.ea.com/blog/f1-games-game-info-hub-en/ea-sports%E2%84%A2-f1%C2%AE25-udp-specification/12187347)
- 核验日期：2026-08-12
- 实现基线：附件中的原始 F1 25 v3 / packet format `2025`，不是 2026 Season Pack 格式。

EA 当前同时发布原始 F1 25 与 2026 Season Pack 两套结构，并允许在游戏设置中选择 UDP mode。首版仅接受 packet format `2025`；其他 format 返回不支持，不尝试按相近偏移猜测。

## 当前实现范围

- `PacketHeader`：29 bytes。
- `PacketCarTelemetryData`：packet id `6`、packet version `1`、22 台车、每车 60 bytes、总长 1352 bytes。
- 通过 `playerCarIndex` 只映射玩家车辆。
- 输出：速度、档位、RPM、转速灯百分比、油门、刹车、DRS、session UID 和 overall frame ID。

解析逐字段读取小端字节，不进行 Rust 结构体内存映射，不使用 `unsafe`。长度、format、packet version、玩家索引、有限浮点、0–1 比例与枚举均严格校验。

## 明确未支持

- F1 25: 2026 Season Pack UDP format。
- 圈速、比赛位置、session、轮胎、损伤、天气、处罚与赛事事件 packet。
- 从邻近年份或未知 packet version 推断兼容。

F1 24 与 F1 25 共享安全 cursor 和已验证的 Car Telemetry 字段实现，但具体 adapter 分别只接受 2024/2025，以交叉拒绝测试防止误识别。
