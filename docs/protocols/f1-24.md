## 解码边界

F1 24 adapter 负责：

1. 校验 packet header、format、version、id、长度、session 和 frame identifier。
2. 按官方小端布局安全读取字段，不使用 `unsafe` 或结构体内存映射。
3. 识别玩家车辆索引，并把多种 packet 合并成标准化更新。
4. 把速度、时间、温度、压力、比例和枚举转换成核心定义。
5. 将完成圈、处罚和其他离散事实转换为事件。
6. 对未知或不兼容包做有速率限制的诊断，不让输入触发 panic。

adapter 不负责 HTTP、WebSocket、布局、显示单位或 UI 文案。

## Fixture 规则

每个 fixture 必须在相邻的 metadata JSON 中记录：

- `packetFormat`、`packetVersion`、`packetId` 和数据报长度。
- 合成、脱敏或录制来源。
- 是否允许公开分发。
- 预期解析字段和误差范围。
- 用于测试的异常条件，例如截断、未知版本或错误玩家索引。

真实录制默认写入仓库根目录下被忽略的 `captures/`，只有人工审查和脱敏后的最小样本才能移动到 `tests/fixtures/f1-24/`。
