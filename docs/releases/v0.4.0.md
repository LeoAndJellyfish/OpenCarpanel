# OpenSimDash v0.4.0 — Sandboxed Game Plugins

`v0.4.0` 将游戏支持从分散在 Host、桌面端与 Dashboard 中的硬编码分支，升级为统一、版本化的游戏插件契约。内置的 F1 24、F1 25（含 2026 Season Pack）、ETS2 与 ATS 现在都由同一种 manifest 描述；第三方开发者也可以在不重新编译 OpenSimDash 的情况下安装跨平台 `.osd-plugin`。

## 主要变化

- 新增 `GamePluginManifest v1` 与 `.osd-plugin` package v1 JSON Schema；
- 新增无 WASI、无 Host import 的 WebAssembly decoder ABI v1；
- Host 可发现、校验、安装、升级、加载和卸载外部游戏插件；
- 桌面控制中心可选择 `.osd-plugin`、预览发布者与版本、确认安装、查看加载错误并卸载；
- 数据源列表、设置步骤、游戏名称与来源标签由运行时插件元数据生成；
- 手机 Dashboard 根据插件声明动态生成主题、默认布局与适用组件；
- 未知第三方插件拥有独立的 `game-<id>` 布局，不会覆盖已有游戏布局；
- 提供 Rust guest SDK、最小示例、`pack` / `validate` CLI 与完整开发指南；
- 固定选择的插件缺失、损坏或被卸载时，Host 安全回退到自动识别并保留诊断原因。

## 安装第三方插件

在桌面控制中心打开“游戏设置”，点击“安装 `.osd-plugin`”。应用会先在有界内存中验证 package、manifest、ABI、模块哈希与 WASM exports，再显示插件名称、版本、发布者和许可证供用户确认。安装完成后 Host 会重载，插件随即出现在游戏标签、数据源列表与手机 Dashboard 中。

外部插件存放在当前用户的数据目录：

- Windows：`%LOCALAPPDATA%\OpenSimDash\game-plugins\<id>\`
- macOS：`~/Library/Application Support/OpenSimDash/game-plugins/<id>/`

卸载不会删除该游戏已经保存的 Dashboard 布局。将来重新安装同一插件 ID 时可以继续使用原布局。

## 沙箱与资源边界

第三方 decoder 不能导入 WASI 或任何 Host 函数，因此不能自行读取文件、访问网络、读取环境变量或调用系统时钟。每次解码还有以下硬限制：

| 资源 | 上限 |
| --- | ---: |
| `.osd-plugin` package | 4 MiB |
| WASM module | 2 MiB |
| linear memory | 4 MiB |
| UDP datagram | 由 manifest 声明，且不超过 65,507 bytes |
| decoder output | 256 KiB |
| fuel / call | 5,000,000 |
| updates / events | 8 / 16 |
| 外部插件数量 | 16 |

Host 还会验证输出 JSON 深度与节点数、字符串长度、事件名、extension namespace 和统一遥测类型，并覆盖 guest 提供的时间戳。超限、trap、哈希不符、ABI 不兼容或损坏插件只会被拒绝并进入脱敏诊断，不会阻止其他游戏适配器与 Host 启动。

`.osd-plugin` v1 暂时没有发布者签名或在线市场。沙箱限制 decoder 的权限，但不能证明包的来源；请只安装来源明确、版本可追踪且最好能够复现构建的插件。

## 开发者入口

完整契约、ABI exports、Rust 示例与命令见[游戏插件开发指南](../plugin-development.md)。最短流程为：

```powershell
rustup target add wasm32-unknown-unknown
cargo build -p opensimdash-example-game-plugin --target wasm32-unknown-unknown --release
cargo run -p opensimdash-game-plugin-cli -- pack examples/game-plugin-rust/manifest.json target/wasm32-unknown-unknown/release/opensimdash_example_game_plugin.wasm example-sim.osd-plugin
cargo run -p opensimdash-game-plugin-cli -- validate example-sim.osd-plugin
```

ABI v1 只允许插件选择 OpenSimDash 内置且受信任的 Dashboard 组件。第三方可执行 JavaScript、CSS、原生动态库、专用监听端口、插件市场和发布者签名不属于本版本范围。

## 兼容性

- 现有 F1 24、F1 25、2026 Season Pack、ETS2 与 ATS 数据链路和游戏内设置不变；
- ETS2/ATS 的 Steam 自动发现、缓存、手动目录选择与 SCS bridge 安装流程保留；
- 配置、配对设备和已有 `game-f1-24`、`game-f1-25`、`game-ets2`、`game-ats` 布局继续使用；
- 内置 adapter 仍是原生 Rust 实现，manifest 与 native descriptor 的漂移会令测试失败；
- package、manifest 和 ABI 当前都精确要求版本 `1`，未知版本会明确拒绝；
- GUI 与独立无头 Host 仍共享实例锁、配置目录与端口。

## 验证范围

自动化覆盖以下关键路径：

- manifest/package Schema 生成与提交文件一致；
- 四个内置 manifest 与原生 adapter descriptor 一致；
- package 哈希、路径与安装边界；
- WASM imports、ABI、内存、fuel、输入、输出、JSON 与事件语义边界；
- 安装后的真实 WASM decoder 经 UDP 更新 Host snapshot；
- 桌面端安装、重载、固定选择、卸载与自动回退；
- 未知第三方游戏的动态 Dashboard 布局和可信组件过滤；
- 现有 F1/SCS fixture、WebSocket、布局迁移、更新与打包烟雾测试；
- 合成 UDP 到 WebSocket p95 保持低于 `100 ms`。

发布仍属于 public preview。Windows 安装器尚未使用 Authenticode 商业证书；macOS 构建采用 ad-hoc 签名，尚未使用 Developer ID 和 notarization。未由自动化替代的真实游戏、手机/iPad 与系统安装验证继续列在[发布检查清单](../release-checklist.md)中。
