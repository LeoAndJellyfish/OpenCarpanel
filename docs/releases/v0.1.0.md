# OpenCarpanel v0.1.0 — first public preview

OpenCarpanel 的首个公开预览版把 Windows/macOS 上的驾驶游戏遥测，通过本地 Rust Host 推送到同一局域网中的手机或 iPad。运行时不依赖云端服务。

## Highlights

- 支持 F1 24（format 2024）、F1 25（原始 format 2025）、Euro Truck Simulator 2 与 American Truck Simulator。
- F1 使用游戏原生 UDP；ETS2/ATS 使用随包的最小 SCS Telemetry SDK loopback 插件。
- 自动识别数据源，并用两秒来源粘性避免多款游戏同时发送时频繁切换；也可显式固定游戏。
- 一次性二维码配对、有界 WebSocket、自动重连、stale 状态与本地脱敏诊断。
- 可定制 Dashboard 和编辑器，支持手机竖屏/横屏、iPad 与桌面断点。
- Windows release 合成 UDP→WebSocket p95 为 `26.65 ms`；包内冒烟依次识别四种协议，4/4 recognized、0 errors。

## Install

从本 Release 下载与系统匹配的 `.tar.gz`，解压后运行 `OpenCarpanel.exe`（Windows）或 `OpenCarpanel`（macOS），然后扫描终端二维码。

- F1 24/25：在游戏 Telemetry Settings 中打开 UDP，目标端口 `20777`；F1 25 必须选择原始 **F1 25 / 2025** UDP mode。
- ETS2/ATS：把包内 `plugins/scs/` 的插件复制到游戏 64 位插件目录，重启游戏并接受 SDK 提示。

完整首启步骤见 [多游戏快速开始](https://github.com/LeoAndJellyfish/OpenCarpanel/blob/v0.1.0/docs/quickstart-multi-game.md)，数据路径与 44 字节协议图见[可视化图解](https://github.com/LeoAndJellyfish/OpenCarpanel/blob/v0.1.0/docs/data-paths-and-scs-packet.md)。

## Known limits

- 这是 unsigned preview；Windows/macOS 正式签名与 notarization 尚未完成。
- F1 只实现 packet id 6 的玩家车辆核心字段；圈速、比赛状态、轮胎、损伤和事件仍在后续范围。
- F1 25 的 2026 Season Pack UDP 格式尚未支持；新用户需要在游戏中切回原始 2025 mode。
- ETS2/ATS 首版映射速度、档位、RPM/RPM 上限、油门和刹车；导航、灯光、油量与任务字段尚未实现。
- 自动化和合成 fixture 已通过，但 F1 25、ETS2、ATS 的完整真实游戏/多设备验收仍按[发布检查清单](https://github.com/LeoAndJellyfish/OpenCarpanel/blob/v0.1.0/docs/release-checklist.md)记录。
