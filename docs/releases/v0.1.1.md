# OpenSimDash v0.1.1 — 2026 Season Pack & game-aware dashboards

这个小版本让 F1 25 的默认 2026 Season Pack UDP 可以直接工作，并让手机/iPad Dashboard 根据当前游戏自动切换布局、视觉和状态语义。所有运行链路仍完全位于电脑与本地局域网内。

## Highlights

- F1 25 adapter 同时严格支持原始 format `2025` 与 2026 Season Pack format `2026`，继续使用稳定的 `f1-25` 游戏 ID。
- 2026 Car Telemetry packet 按官方结构验证：29 字节公共头、24 台车、每车 59 字节、总长 1448 字节。
- Dashboard 根据 canonical telemetry 的 `meta.gameId` 自动选择 F1 24、F1 25、ETS2 或 ATS presentation profile。
- F1 页面保留转速灯地平线、大档位和 DRS；卡车页面改为速度优先、低转速量程、道路视觉与 SCS bridge 状态。
- 四款游戏拥有独立持久化布局；编辑器可明确选择游戏，切换时保存本机草稿，不会覆盖另一款游戏。
- 升级时会把 `v0.1.0` 已保存的单一 `default` 布局安全复制到新的游戏布局 ID，原文件继续保留。
- 包内冒烟使用临时 loopback 端口，因此可以在旧版 Host 正在运行时验证新包，而不会抢占用户端口。

## Install / upgrade

从本 Release 下载与系统匹配的 `.tar.gz`，退出旧版 Host，解压新包后运行 `OpenSimDash.exe`（Windows）或 `OpenSimDash`（macOS），再扫描终端二维码。

- F1 24/25：打开 UDP Telemetry，目标端口 `20777`；F1 25 的原始 2025 和 2026 Season Pack mode 均可。
- ETS2/ATS：把新包 `plugins/scs/` 内的插件复制到游戏 64 位插件目录，重启游戏并接受 SDK 提示。
- `v0.1.0` 的布局和 Host 数据目录无需删除；首次打开对应游戏页面时自动完成兼容迁移。

完整步骤见[多游戏快速开始](https://github.com/LeoAndJellyfish/OpenSimDash/blob/v0.1.1/docs/quickstart-multi-game.md)，协议结构见 [F1 25 UDP 边界](https://github.com/LeoAndJellyfish/OpenSimDash/blob/v0.1.1/docs/protocols/f1-25.md)。

## Known limits

- 这是 unsigned preview；Windows/macOS 正式签名与 notarization 尚未完成。
- F1 仍只映射 packet id `6` 的玩家车辆核心字段；2026 新增的 Car Telemetry 2（packet id `16`）及主动空气动力学尚未展示。
- ETS2/ATS 尚未映射导航、灯光、油量和任务字段。
- 合成 fixture、自动化和页面视觉检查已完成，但真实 F1 25/2026、ETS2、ATS 与多种手机/iPad 的完整验收仍按[发布检查清单](https://github.com/LeoAndJellyfish/OpenSimDash/blob/v0.1.1/docs/release-checklist.md)记录。
