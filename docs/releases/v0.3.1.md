# OpenSimDash v0.3.1 — Adaptive Dashboard Telemetry

`v0.3.1` 将 v0.3.0 已接入协议与适配器的扩展遥测正式带到手机和 iPad 仪表盘。Dashboard 现在会随当前游戏自动装载对应信息密度与布局：F1 强调比赛、圈速、轮胎和车况，ETS2/ATS 强调导航、任务、燃油和灯光。全部数据仍只在游戏电脑与同一局域网内传输。

## F1 24 / F1 25

- 新增 **Race** 面板：名次、当前/总圈数、圈速、相对最佳圈 Delta、剩余时间、天气、空气/赛道温度、燃油圈数、旗帜、安全车和处罚状态。
- 新增 **Tyres & damage** 面板：四轮温度、胎压、磨损、轮胎损伤与关键车辆损伤/系统故障摘要。
- F1 25 运行 2026 Season Pack 时，Race 面板会在 packet 16 数据存在时显示主动空气动力学模式和超车状态。
- 不支持或尚未收到的字段统一显示 `—`，不会把缺失数据当作零值，也不会产生运行时异常。

## Euro Truck Simulator 2 / American Truck Simulator

- 新增 **Route & job** 面板：剩余路线距离、ETA、道路限速、油量、续航、起终点、货物与质量。
- 近光、远光、左右转向、双闪和警示灯以紧凑状态灯呈现。
- 卡车默认布局重新分配速度、挡位、转速、连接状态与行程面板，在手机横屏、竖屏和平板上使用不同网格。

## 自定义布局与升级

- 编辑器组件目录新增 `core.race`、`core.tyres` 与 `core.route`，可继续移动、删除、导入和导出。
- F1 内置布局由四个组件扩展为六个，ETS2/ATS 内置布局扩展为五个。
- Host 只会自动升级 revision `1` 且仍与 v0.3.0 内置签名一致的未修改默认布局。
- 已保存过的自定义布局、改名布局和更高 revision 均保持原样；用户可在编辑器中自行添加新面板。

## 性能与稳定性

- 新面板沿用单一 `requestAnimationFrame` 合帧循环，UDP/WebSocket 快照只更新最新内存状态，不触发逐包 Preact 组件重渲染。
- Store 仅保留最新的 lap/session/tyres/conditions/damage/aero/navigation/lights/job 对象，不积累历史样本。
- 游戏或 session 切换时清除插值历史并使全部订阅字段失效，避免跨游戏残影。

## 验证

- Dashboard、Widget SDK 与桌面控制中心严格 TypeScript 检查通过。
- 46 项 Web 测试通过，包含扩展字段映射、格式化、布局无碰撞、编辑器导入/编辑和 rAF 合帧行为。
- Host layout API 7 项测试通过，覆盖旧默认布局升级与 revision `2` 自定义布局保留。
- 390×844 手机竖屏、844×390 手机横屏和 1024×768 平板演示数据截图检查通过；页面 scroll 尺寸与视口一致，无水平或垂直溢出。
- Release 工作流仍会在发布前执行 workspace fmt、Clippy `-D warnings`、Rust/Web 全量测试、Host 打包烟雾测试，以及 Windows x64、macOS Apple Silicon、macOS Intel 三平台安装包和更新签名核验。

## 安装与已知边界

- Windows x64 优先下载 NSIS `setup.exe`；Apple Silicon 与 Intel Mac 分别下载对应架构 DMG。
- 可从 v0.3.0 直接升级，配置、设备凭据、网络设置和自定义 Dashboard 布局会保留。
- 安装程序尚未使用 Windows Authenticode 或 Apple Developer ID/notarization，因此本版本仍为 public preview。
- 真实游戏、干净操作系统、手机/iPad 长时帧率和端到端延迟验收继续记录在[发布检查清单](../release-checklist.md)。
