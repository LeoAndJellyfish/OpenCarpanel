# OpenCarpanel v0.3.3 — Automatic Steam Game Discovery

`v0.3.3` 让 ETS2 / ATS 首次配置不再依赖用户手工定位 Steam 深层目录。桌面控制中心会在用户打开对应游戏设置时自动查找安装位置，成功后直接展示 bridge 状态；查找失败不会阻断向导，原有系统文件夹选择器始终保留。

## Steam 自动发现

- Windows 从当前用户和本机 Steam 注册表位置开始，并补充系统盘常见安装目录。
- macOS 从当前用户的 `Library/Application Support/Steam` 开始；Linux 源码构建也覆盖常见原生与 Flatpak 数据目录。
- 自动解析当前与旧版 `steamapps/libraryfolders.vdf`，因此游戏可以位于默认库或任意额外 Steam 库。
- ETS2 只读取 `appmanifest_227300.acf`，ATS 只读取 `appmanifest_270880.acf`；manifest 内的 AppID 必须与目标游戏完全一致。
- 使用 manifest 的 `installdir` 推导 `steamapps/common` 下的游戏根目录，不扫描整块磁盘，也不调用 Steam Web API。

## 路径安全与本地缓存

- `installdir` 只能是单个普通目录名，包含绝对路径、父目录、斜杠或反斜杠的值都会被拒绝。
- 候选目录继续经过既有规范化、平台 64 位程序目录与符号链接逃逸校验；自动发现不会降低手动安装向导的安全边界。
- 通过验证的自动或手动目录分别写入本机版本化 `scs-installations.json`。下次启动先重新校验缓存；缓存失效时再查询 Steam。
- 缓存是可重建的桌面本地状态，不进入 Host 网络诊断，不包含 Steam 凭据、账户信息或游戏存档。
- 自动发现只读取路径，不会修改 Steam 配置、移动游戏或自动写入 SCS bridge；插件安装仍需要用户明确点击。

## 桌面界面

- ETS2 与 ATS 分别保存目录和发现阶段，切换标签不会让一款游戏覆盖另一款。
- 目录区域明确显示等待、查找中、Steam 已找到、未找到、失败或手动选择状态，并使用 `aria-live` 通知辅助技术。
- 自动查找期间仍可打开系统目录选择器；用户操作会使在途自动结果失效，避免覆盖手动选择。
- 在未找到或读取失败后重新选择游戏标签会重试，手动选择始终可用。

## 兼容性与升级

- 可从 v0.3.2 直接升级；Host 设置、配对设备、Dashboard 布局和遥测协议均不变。
- 新增的 `scs-installations.json` 独立于现有 Host 配置，损坏时会被安全重建，不影响 Host 启动。
- F1 24、F1 25 原始 2025 模式、2026 Season Pack、SCS bridge v1/v2 与手机仪表盘数据格式没有变化。
- Windows 注册表读取依赖仅在 Windows 目标编译，不增加 macOS 常驻内存或运行时服务。

## 验证

- Rust 测试覆盖现代/旧版 VDF、多个 Steam 库、AppID 不匹配、危险 `installdir`、无效候选跳过、ETS2/ATS 独立缓存及损坏缓存重建。
- 本机真实 Steam 数据只读验证确认注册表、`libraryfolders.vdf`、ETS2 `227300` manifest、`installdir` 与 `bin/win_x64` 链路一致。
- 真实 Chromium 演示验证 ETS2 → ATS → ETS2 切换时各自目录保持正确；唯一控制台错误为既有 `favicon.ico` 404。
- 本地门禁通过 workspace fmt、Clippy `-D warnings`、全量 Rust tests、63 项 Web tests、Windows SCS plugin native test、资源 staging 与 desktop production build。
- Release 工作流继续生成 Windows x64 NSIS/MSI、macOS Apple Silicon/Intel DMG 与签名更新包；只有 11 个资产和 `latest.json` 全部核验后才公开 Release。

## 安装与已知边界

- Windows x64 优先下载 NSIS `setup.exe`；Apple Silicon 与 Intel Mac 分别下载对应架构 DMG。
- 安装程序尚未使用 Windows Authenticode 或 Apple Developer ID/notarization，因此本版本仍为 public preview。
- 真实 ATS 安装、macOS Steam 库与游戏插件加载仍需按[发布检查清单](../release-checklist.md)进行实机验收；自动化验证不能替代这些项目。
