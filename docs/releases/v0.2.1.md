# OpenCarpanel v0.2.1 — SCS Directory Selection Fix

`v0.2.1` 是桌面控制中心的补丁版本，修复 Windows/macOS 安装包中选择有效 ETS2/ATS 游戏目录后仍显示“尚未选择游戏目录”的问题。遥测协议、配置格式、配对数据和 Dashboard 布局均未改变。

## 修复

- 修正 Tauri 资源目录解析：安装器使用 `resources/**/*` 时会保留顶层 `resources`，SCS bridge 现在从实际的 `resources/plugins/scs` 查找。
- 同时保留 `plugins/scs` 扁平资源布局兼容，避免开发构建或未来显式资源映射再次出现同类问题。
- 选择有效 ETS2/ATS 根目录后，控制中心现在可以完成 bridge 哈希检查、显示目标路径并启用安装按钮。

## 安装与更新

- Windows x64：优先下载 NSIS `setup.exe`。
- Apple Silicon：下载 `aarch64` DMG。
- Intel Mac：下载 `x86_64` DMG。
- 已安装 v0.2.0 的用户可以使用控制中心内置更新器升级；更新包仍由独立私钥签名并在执行前强制验签。

安装程序尚未使用 Windows Authenticode 或 Apple Developer ID/notarization，因此 v0.2.1 仍标记为 public preview。macOS 首次打开可能需要在 **System Settings → Privacy & Security** 中允许。

## 兼容性

- F1 24：UDP format 2024。
- F1 25：UDP format 2025 与 2026 Season Pack format 2026。
- Euro Truck Simulator 2 / American Truck Simulator：随安装包的 SCS SDK 1.14 bridge。
