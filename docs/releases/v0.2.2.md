# OpenSimDash v0.2.2 — Desktop Interface Refinement

`v0.2.2` 是桌面控制中心的界面精简版本。它移除重复、教程式和实现细节导向的说明文字，让各页面优先展示当前状态、目标值和可执行操作。遥测协议、配置格式、设备凭据、Dashboard 布局与本地数据链路均未改变。

## 界面改进

- 精简总览、设备与配对、游戏设置、仪表盘、网络、系统与诊断页面中的重复解释。
- F1 24/25 设置向导直接对应游戏内的 `UDP Telemetry`、`UDP IP Address`、`UDP Port / Send Rate` 和 `UDP Format` 字段。
- ETS2/ATS 向导直接显示游戏目录、SCS Bridge 状态、重启要求和本地遥测目标。
- 系统开关只在功能不可用时说明原因；更新说明只在实际发现新版本时显示。
- 保留错误、恢复、活动游戏、数据新鲜度、端口、安装路径和版本等必要状态。
- 为桌面开关补充可访问名称，精简视觉文案不会降低辅助技术可用性。

## 安装与更新

- Windows x64：优先下载 NSIS `setup.exe`。
- Apple Silicon：下载 `aarch64` DMG。
- Intel Mac：下载 `x86_64` DMG。
- 已安装 v0.2.1 的用户可以使用控制中心内置更新器升级；更新包继续由独立私钥签名并在执行前强制验签。

安装程序尚未使用 Windows Authenticode 或 Apple Developer ID/notarization，因此 v0.2.2 仍标记为 public preview。macOS 首次打开可能需要在 **System Settings → Privacy & Security** 中允许。

## 兼容性

- F1 24：UDP format 2024。
- F1 25：UDP format 2025 与 2026 Season Pack format 2026。
- Euro Truck Simulator 2 / American Truck Simulator：随安装包的 SCS SDK 1.14 bridge；保留 v0.2.1 的打包资源目录修复。
- v0.2.1 的配置、配对设备与每游戏 Dashboard 布局可直接沿用。
