# OpenSimDash v0.3.0 — Expanded Game Telemetry

`v0.3.0` 是 OpenSimDash 的遥测能力升级版本。F1 24、F1 25 与 2026 Season Pack 从基础驾驶数据扩展到圈速、比赛状态、赛事事件、轮胎、损伤、天气、处罚、燃油和 ERS；ETS2/ATS 则通过新的 SCS bridge v2 增加导航、油量、灯光与配送任务。运行时仍完全位于游戏电脑和同一局域网内，不依赖远程服务。

## F1 遥测扩展

- F1 24 严格解析 Session、Lap Data、Event、Car Telemetry、Car Status 与 Car Damage packets（ID `1/2/3/6/7/10`）。
- F1 25 同时支持原始 format `2025` 与 2026 Season Pack format `2026`，按各自车辆数、entry stride 和总包长隔离解析。
- 新增圈号、位置、圈速/分段、前车与领跑者差距、赛道距离、维修区状态、警告、处罚和比赛结果状态。
- 新增天气、空气/赛道温度、安全车、FIA 旗帜、轮胎温度/胎压/磨损/损伤/起泡、车身与动力单元损伤、燃油和 ERS。
- Event packet 输出结构化比赛开始/结束、最快圈、处罚、退赛、超车、安全车、红旗、碰撞等事件；圈号递增生成 `lap.completed`。
- 2026 Season Pack 精确支持 24 车、269-byte packet 16，输出主动空气动力学、超车可用/激活距离、2026 规则与逆行状态。
- reducer 按 session 和 frame 防止旧包覆盖新状态，并按字段合并来自不同 packet 的四轮温度、胎压和损伤。

实现布局依据 [EA SPORTS F1 25 2026 Season Pack UDP Specification](https://forums.ea.com/blog/f1-games-game-info-hub-en/ea-sports%E2%84%A2-f1%C2%AE25-2026-season-pack-udp-specification/12187347)以及仓库记录的 F1 24 v27.2x、原始 F1 25 v3 和 2026 v10.0 文档基线。

## ETS2 / ATS SCS bridge v2

- 随包原生插件改用固定 188-byte v2 loopback UDP 协议，同时 Host 继续接受旧版 44-byte v1 报文。
- 新增剩余导航距离/时间、道路限速、当前油量、油箱容量、预计续航和低油量警告。
- 新增示宽灯、近光、远光、警示灯、刹车灯、倒车灯、左右转向与双闪状态。
- 新增货物、质量、起点/终点城市、收入、交付期限、计划里程、装载状态与特殊运输状态。
- 文本在 UTF-8 code-point 边界截断并零填充；Host 严格验证长度、magic、版本、保留位、bit mask、数值、UTF-8 与 padding。
- 插件只向 `127.0.0.1:20777` 非阻塞发送，不监听端口，不读取存档，不执行 DNS、重试或远程通信。

精确 wire layout 与教材式分段图见 [SCS bridge v2 协议](../protocols/scs-bridge-v2.md)和[游戏数据链路与 SCS 数据包协议图解](../data-paths-and-scs-packet.md)。

## 桌面控制中心

- 删除侧栏和页面中的英文副标题、重复介绍、实现细节说明，以及总览中意义不明确的重复数据面板。
- 保留关键状态、错误、恢复操作、目标路径、端口与版本信息，界面继续沿用现有视觉风格。
- 开发模式使用独立 `devCsp`，允许 Vite 动态样式与本地热更新 WebSocket；正式安装包继续使用严格生产 CSP。

## 安装、升级与兼容性

- Windows x64：优先下载 NSIS `setup.exe`。
- Apple Silicon：下载 `aarch64` DMG。
- Intel Mac：下载 `x86_64` DMG。
- v0.2.2 的配置、配对设备、网络设置和 Dashboard 布局可直接沿用。
- 已安装 v0.2.2 的用户可通过控制中心内置更新器升级；更新包继续由独立私钥签名并在执行前强制验签。

安装程序尚未使用 Windows Authenticode 或 Apple Developer ID/notarization，因此 v0.3.0 仍标记为 public preview。macOS 首次打开可能需要在 **System Settings → Privacy & Security** 中允许。
