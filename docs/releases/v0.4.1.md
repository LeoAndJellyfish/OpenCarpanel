# OpenSimDash v0.4.1 — Project Rename

`v0.4.1` 将项目正式更名为 **OpenSimDash**。新名称强调这是面向模拟驾驶游戏的开放仪表盘，而不是实体汽车软件；F1 24、F1 25（含 2026 Season Pack）、ETS2、ATS 与第三方游戏插件继续共用同一个本地 Rust Host 和手机 Dashboard。

## 全量改名

- 桌面控制中心、手机 Dashboard、托盘、通知、诊断、日志和打包资源统一显示 `OpenSimDash`；
- Rust workspace、npm workspace、CLI、无头 Host 与 SCS telemetry bridge 统一使用 `opensimdash` 命名；
- 应用标识、环境变量、数据目录、单实例锁、更新地址、安装包和 updater manifest 使用新品牌；
- GitHub 仓库、Issue、项目看板、README、架构文档、协议图与发布说明指向 `LeoAndJellyfish/OpenSimDash`；
- SCS loopback bridge magic 与示例 UDP magic 使用 `OSD` 前缀。

## 不兼容的插件变更

游戏插件包现在必须以 `.osd-plugin` 结尾。桌面文件选择器、Host 安装入口和开发者 CLI 都执行同一项严格、区分大小写的扩展名检查；改名或复制成其他扩展名的文件不会被安装。

WASM ABI 导出同步改为：

```text
osd_plugin_abi_version() -> i32
osd_input_ptr() -> i32
osd_input_capacity() -> i32
osd_output_ptr() -> i32
osd_output_capacity() -> i32
osd_decode(input_len: i32, received_at_us: i64) -> i32
```

本版本不包含旧插件包、ABI、环境变量或单实例标识的兼容层。第三方插件应使用 `v0.4.1` SDK 重新编译，并由新的 CLI 重新打包：

```powershell
cargo build -p opensimdash-example-game-plugin --target wasm32-unknown-unknown --release
cargo run -p opensimdash-game-plugin-cli -- pack examples/game-plugin-rust/manifest.json target/wasm32-unknown-unknown/release/opensimdash_example_game_plugin.wasm example-sim.osd-plugin
cargo run -p opensimdash-game-plugin-cli -- validate example-sim.osd-plugin
```

## 用户资料迁移

首次使用新版本且 OpenSimDash 资料目录尚不存在时，GUI 与无头 Host 会先取得上一份资料的实例锁，再通过同文件系统 staging 目录复制并原子提交以下内容：

- 设置与网络端口；
- 已配对设备；
- 每款游戏的自定义布局；
- ETS2/ATS 安装目录发现缓存及其他有界用户状态。

不兼容的第三方插件、运行时锁和历史日志不会迁移。旧资料目录不会删除，可作为人工恢复备份；如果新资料目录已经存在，则永远不会覆盖。

## 本地运行与分发边界

遥测接收、配对、WebSocket 推送、布局编辑和第三方 WASM 解码仍完全在游戏电脑与局域网内运行。只有启用更新检查时才访问 GitHub Releases。

Windows 安装包尚未使用 Authenticode 商业证书；macOS 安装包采用 ad-hoc 签名且尚未 notarize。因此 `v0.4.1` 继续作为 public preview 发布，系统可能显示未知发布者或要求用户在 Privacy & Security 中手动放行。

完整自动化与实机边界见[发布检查清单](../release-checklist.md)。
