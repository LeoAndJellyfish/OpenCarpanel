# OpenCarpanel v0.2.0 — Desktop Control Center

`v0.2.0` 把桌面端从终端入口升级为 Tauri 2 控制中心，同时保留原来的低内存无头 Rust Host 和手机/iPad Web Dashboard。驾驶数据仍只在游戏电脑和局域网内流动。

## 新增

- 一个进程内直接运行 Rust Host 的 Windows/macOS GUI，不额外拉起后台服务。
- 游戏自动识别、实时链路/包计数、F1 24/F1 25 2026 设置向导。
- ETS2/ATS 系统目录选择器与安全 bridge 安装：路径归一化、拒绝 symlink escape、旧版本备份、原子替换和 SHA-256 复核。
- 一次性二维码、已配对设备列表与撤销。
- Dashboard/编辑器入口、网络端口与 20/30/60 Hz 设置、日志目录和恢复状态。
- 系统托盘、关闭到托盘、登录时启动、可选通知和每日最多一次的自动更新检查。
- GUI 与 CLI 共用配置、设备库和跨进程 singleton；第二个入口会报告现有 GUI/CLI 所有者并退出。

## 安装

- Windows x64：优先下载 NSIS `setup.exe`。
- Apple Silicon：下载 `aarch64` DMG。
- Intel Mac：下载 `x86_64` DMG。

安装目录同时包含 `opencarpanel-host`，供自动化或不需要 GUI 的用户使用。不要同时启动它和桌面控制中心。

macOS 包目前使用 ad-hoc signature，尚未使用 Apple Developer ID/notarization；首次打开可能需要在 **System Settings → Privacy & Security** 中允许。Windows 安装器也尚未使用 Authenticode 商业证书。两者因此都属于 public preview。

## 更新安全

应用内 updater 与操作系统代码签名是两层不同机制。OpenCarpanel 的更新产物由离线私钥签名，应用编译入公钥并强制验签；Host 在下载和签名验证期间保持运行，只在准备启动已验证安装器时停止。自动检查可以完全关闭，驾驶流程不依赖更新服务。当前安装器若下载或验签失败不会被执行。

## 游戏兼容

- F1 24：UDP format 2024。
- F1 25：UDP format 2025 与 2026 Season Pack format 2026。
- Euro Truck Simulator 2 / American Truck Simulator：随安装包的 SCS SDK 1.14 bridge。

手机 Dashboard 继续根据 `gameId` 自动切换方程式/卡车页面与各游戏独立布局。字段范围没有伪装扩大，仍以速度、档位、RPM、油门、刹车及 F1 DRS 为主。

## 验证与边界

Windows 的单元/集成、native bridge、Host package smoke、Tauri 安装器生成和多尺寸 production UI 视觉检查已完成。跨平台 CI 负责生成 Windows x64、macOS Apple Silicon 与 macOS Intel 产物，并在三者全部存在、`latest.json` 聚合完整后才发布 Release。

真实 F1/SCS 游戏、干净 OS、手机/iPad、长时 soak 与系统签名状态逐项记录在[发布检查清单](../release-checklist.md)，未完成项不会用合成 fixture 冒充实测。
